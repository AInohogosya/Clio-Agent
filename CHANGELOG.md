### Security
- Added .env.example templates to prevent accidental secret commits
- Updated .gitignore to exclude sensitive files

## [1.0.0] - 2024-XX-XX

### Added
- Autonomous AI agent with multi-platform support (CLI, Telegram, Discord, WhatsApp)
- Multi-provider LLM routing (OpenAI, Google, Anthropic, OpenRouter, Grok, DeepSeek, and more)
- Tool system: file operations, web search, shell commands, local search
- Context management with auto-compression and persistence
- Autonomous mode with configurable thinking interval
- Retry logic with exponential backoff
- Meta-controller for stuck detection
- LLM settings lock (guardrail against prompt injection)
- Interactive configuration wizard
- Comprehensive test suite
- Full documentation
